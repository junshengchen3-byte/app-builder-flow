# Product Discovery Questions

Use these questions to identify the product before planning or coding. Ask only what materially changes the plan. Do not ask the entire list at once; select the smallest useful batch.

## Core Intent

- What app are we building?
- Who is the primary user?
- What job should the app help them finish?
- What is the first moment where the user should feel value?
- What existing workflow is this replacing or improving?

## MVP Boundary

- What are the three to five must-have features for version 1?
- What features are tempting but should be excluded from version 1?
- Does the app need login, cloud sync, payments, AI, collaboration, notifications, or admin tools?
- What data must be stored? Is it local-only or shared across devices?
- What permissions are needed: camera, microphone, photos, location, contacts, calendar, Bluetooth, notifications?

## Platform And Release

- Target platform: iOS, Android, web/PWA, desktop, mini program, or multiple platforms?
- Is App Store / Play Store / public web release required for version 1?
- Is there an existing developer account, domain, backend, design file, or brand asset?
- What devices or screen sizes must be supported?

## Design Inputs

- What app or visual reference should influence the style?
- Should the UI feel dense and tool-like, simple and consumer-facing, editorial, playful, or enterprise?
- What brand name, icon concept, colors, and typography direction are known?
- Are there screenshots or sketches to follow?

## Business Constraints

- Is monetization required in version 1?
- Are there privacy, compliance, content moderation, or user safety constraints?
- What deadline or budget constraint affects the technical route?
- What would make the first release unacceptable?
